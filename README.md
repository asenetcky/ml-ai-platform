# AI & Machine Learning Tailnet Platform

## Description

This is a basic outline of a Tailscale + Container based AI + Machine Learning 
experimentation platform for myself. This is largely based off of the tutorials
from Tailscale's youtube videos with Alex K. 

### Contents

- [Ollama](https://github.com/ollama/ollama) for pulling/managing AI models in the backend/cli
- [Open WebUI](https://github.com/open-webui/open-webui) for a lovely self-hosted AI GUI
